## What is miniCycle?

miniCycle is a **routine-building task manager** that helps you establish consistent habits and processes. Unlike traditional to-do apps that focus on one-time tasks, miniCycle is designed for **repeating routines** that cycle.

### Key Differences from To-Do Apps

| Traditional To-Do App | miniCycle |
|----------------------|-----------|
| Tasks deleted when done | Tasks reset and repeat |
| Focus on one-time actions | Focus on routines and habits |
| Linear progress | Cyclical progress |
| Task list empties | Task list persists |

### Who Should Use miniCycle?

- **Routine-oriented people** who repeat the same tasks regularly
- **Process followers** who have checklists or procedures
- **Habit builders** establishing new routines
- **Teams** with recurring workflows
- Anyone who finds themselves recreating the same to-do list over and over

## Basic Concepts

### What is a Cycle?

A **cycle** is a named collection of tasks that represent a routine or process. Examples:
- "Morning Routine"
- "Weekly Cleaning"
- "Project Checklist"
- "Workout Plan"

### What Happens When You Complete a Cycle?

When all tasks in a cycle are checked off:
- ✅ **Cycle count increments** (tracks how many times you've completed it)
- 🔄 **Tasks reset to unchecked** (ready for next time)
- 📊 **Stats update** (completion rate, streaks)
- 🎉 **Celebration animation** (optional)

This is the core "cycling" concept that makes miniCycle unique!

## Creating Your First Cycle

### Step 1: Create a New Cycle

1. Click the **menu icon** (☰) in the top-left
2. Select **"Switch Cycle"**
3. Click **"Create New Cycle"**
4. Enter a name (e.g., "Morning Routine")
5. Click **"Create"**

### Step 2: Add Tasks

There are three ways to add tasks:

**Method 1: Quick Add**
1. Type task name in the input box at the top
2. Press **Enter** or click **"Add Task"**

**Method 2: Task Menu**
1. Click the **"+"** button
2. Enter task details
3. Optionally set due date, priority, or recurring schedule

**Method 3: Import**
1. Click menu → **"Settings"**
2. Select **"Import Cycle"**
3. Choose a `.mcyc` file

### Step 3: Customize Tasks

For each task, you can:
- ✏️ **Edit** the task name
- ⭐ **Mark as high priority** (shows with colored indicator)
- 📅 **Set a due date** (optional reminders)
- 🔄 **Make recurring** (auto-recreates on schedule)
- 🗑️ **Delete** if no longer needed

**How to access task options:**
- **Desktop:** Hover over task → three dots (⋮) appear
- **Mobile:** Long-press task → options appear

## Routine Switcher Modal

The Routine Switcher lets you manage all your routines in one place. Access it via **Menu (☰) → Switch Cycle** or the folder icon button.

### Visual Mode Indicators

Each routine shows its mode at a glance with emojis:
- 🔄 **Auto Cycle** - Tasks auto-reset when complete
- ✋ **Manual Cycle** - You control when to reset
- 📋 **To-Do Mode** - Completed tasks are deleted

### Sorting Routines

Click the **Sort** dropdown to organize your routine list:
- **Name** - Alphabetical order (A-Z)
- **Date Created** - Newest or oldest first
- **Date Modified** - Recently changed first
- **Mode** - Group by Auto/Manual/To-Do

### Filtering by Mode

Use the **Filter** dropdown to show only specific routine types:
- **All Modes** - Show everything
- **🔄 Auto Cycle** - Only auto-cycling routines
- **✋ Manual** - Only manual cycle routines
- **📋 To-Do** - Only to-do mode routines

### Date Information

Each routine shows when it was last modified or created:
- **Modified [date]** - Shows when routine was last changed
- **Created [date]** - Shows for new routines that haven't been modified yet

### Duplicating Routines

Create a copy of any routine:
1. Select a routine in the list
2. Click the **Duplicate** button
3. A new routine appears as "[Name] Copy"
4. The name is highlighted for immediate editing - type a new name
5. Press **Enter** to save or **Escape** to keep the default name

**Use cases:**
- Create variations of existing routines
- Back up a routine before making major changes
- Share a template with different names for different contexts

### Other Actions

- **Rename** - Change the routine name
- **Delete** - Remove the routine (with confirmation)
- **Export** - Save as `.mcyc` file
- **Import** - Load routines from `.mcyc` files (drag-and-drop supported)

## Working with Tasks

### Checking Off Tasks

Simply **click the checkbox** next to any task to mark it complete.

**What happens:**
- ✅ Task is marked complete
- 📊 Progress bar updates
- 🎯 Cycle completion may trigger (if all tasks done)

### Unchecking Tasks

Click the checkbox again to uncheck a completed task.

**Use cases:**
- Made a mistake
- Need to redo the task
- Want to defer completion

### Reordering Tasks

**Desktop:**
- Click and drag tasks up/down

**Mobile:**
- Long-press → drag when handles appear
- OR use arrow buttons (⬆️⬇️) in task options

**Tip:** Order tasks by sequence (e.g., morning routine in chronological order)

### Editing Tasks

1. Click the **three dots (⋮)** on the task
2. Select **"Edit"**
3. Modify the task name
4. Press **Enter** or click outside to save

**Keyboard shortcut:** Double-click task text to edit directly

### Deleting Tasks

1. Click the **three dots (⋮)** on the task
2. Select **"Delete"**
3. Confirm deletion

**Warning:** Deleted tasks cannot be recovered unless you have a backup!

## Understanding Modes

miniCycle has **three operational modes** to match different workflows. **Mode changes apply instantly without page reload (v1.372+)** - your tasks update in real-time!

### 1. Auto Cycle Mode 🔄 (Default)

**How it works:**
- Complete all tasks → cycle **automatically resets**
- Best for: Daily routines, habits, recurring checklists

**Example:** Morning routine automatically resets every day when completed.

**Pros:**
- ✅ Hands-free operation
- ✅ Encourages consistency
- ✅ Great for habits

**Cons:**
- ⚠️ Can't review completed state (resets immediately)

---

### 2. Manual Cycle Mode ✋

**How it works:**
- Complete all tasks → **"Complete Cycle" button appears**
- You manually click button to reset
- Best for: Weekly reviews, project phases, intentional resets

**Example:** Weekly cleaning checklist that you review before resetting.

**Pros:**
- ✅ Control over when to reset
- ✅ Can review completed state
- ✅ Intentional completion

**Cons:**
- ⚠️ Requires manual action

**How to enable:**
1. Menu → **Settings**
2. Find your cycle's settings
3. Toggle **"Manual Cycle Mode"**

---

### 3. To-Do Mode 📋

**How it works:**
- Completed tasks are **deleted** (not reset)
- Click **"Clear Completed Tasks"** button to remove all checked tasks
- A **"🧹 X tasks cleared!"** message confirms the action
- Best for: One-time tasks, traditional to-do lists

**Example:** Project tasks that won't repeat.

**Pros:**
- ✅ Familiar to-do list behavior
- ✅ List empties as you complete
- ✅ Good for one-time projects
- ✅ Visual feedback when tasks are cleared

**Cons:**
- ⚠️ Tasks don't repeat (defeats cycling concept)

**How to enable:**
1. Menu → **Settings**
2. Find your cycle's settings
3. Toggle **"To-Do Mode"**

## Recurring Tasks

Recurring tasks **automatically recreate** themselves on a schedule.

### When to Use Recurring Tasks

- ✅ Tasks that repeat on a predictable schedule
- ✅ Time-sensitive reminders
- ✅ Maintenance tasks (daily, weekly, monthly)

**Examples:**
- "Take medication" (daily at 9 AM)
- "Water plants" (every 3 days)
- "Pay rent" (1st of every month)
- "Backup files" (every Sunday)

### Creating a Recurring Task

1. Add a task normally
2. Click **three dots (⋮)** → **"Make Recurring"**
3. Choose schedule:
   - **Hourly** (e.g., every 2 hours)
   - **Daily** (e.g., every day at 8 AM)
   - **Weekly** (e.g., every Monday and Friday)
   - **Monthly** (e.g., 15th of every month)
   - **Yearly** (e.g., January 1st)
4. Set duration (forever, X times, or until date)
5. Click **"Save"**

### Understanding Recurring Behavior

**Scenario 1: Task Not Yet Due**
- Recurring task **won't appear** in your list yet
- Appears automatically when scheduled time arrives

**Scenario 2: Task is Due**
- Task appears in your list
- Check it off when complete
- Task disappears until next scheduled time

**Scenario 3: Missed a Task**
- If you miss a scheduled occurrence, task **still appears**
- Only one instance appears (not multiple for missed times)
- Check it off whenever you get to it

**Scenario 4: During Cycle Reset**
- Recurring tasks are **removed** during cycle reset
- They'll reappear at next scheduled time

### Editing Recurring Tasks

1. Click **three dots (⋮)** → **"Edit Recurring"**
2. Modify schedule or duration
3. Click **"Save"**

Changes apply to **future occurrences** only.

### Stopping Recurring Tasks

1. Click **three dots (⋮)** → **"Stop Recurring"**
2. Task becomes a regular task
3. Won't recreate anymore

## Customization

### Task Button Customization (v1.373+)

**Customize which buttons appear on each task - make your cycles as simple or feature-rich as you need!**

miniCycle lets you control which action buttons show on each task, per cycle. This means your morning routine can be ultra-minimal while your work project cycle has all the features.

#### How to Customize

1. Click the **`-/+`** button on any task
2. A modal opens showing all available buttons
3. Check/uncheck options to show/hide buttons
4. Changes apply immediately - no save button needed!

**Per-Cycle Settings** (different for each routine):
- ⚡ **High Priority** - Mark important tasks

- 🔁 **Recurring** - Set tasks to auto-recreate
- 📅 **Due Date** - Add deadlines
- 🔔 **Reminders** - Get notifications
- ❌ **Delete When Complete** - Auto-remove during reset (v1.370+)

**Global Settings** (same across all cycles):
- ▲▼ **Move Arrows** - Reorder tasks with arrows
- ⋮ **Three Dots** - Access options via dropdown menu

#### Real-World Examples

**Minimal Morning Routine:**
- ✅ High Priority, Rename, Delete
- ❌ Recurring, Due Date, Reminders
- Result: Clean 3-button interface

**Full-Featured Work Projects:**
- ✅ All buttons enabled
- Result: Complete 9-button toolkit

**Quick Shopping List:**
- ✅ Rename, Delete only

## Tips & Best Practices

### 🎯 For Daily Routines

1. **Order matters** - Put tasks in chronological order
2. **Start small** - Don't add too many tasks at first
3. **Be specific** - "Morning stretches (10 min)" better than "Exercise"
4. **Track time** - Add duration estimates to tasks
5. **Review weekly** - Adjust tasks that aren't working

---

### 🔄 For Recurring Workflows

1. **Use descriptive names** - "Weekly: Review analytics" better than "Check stats"
2. **Set reminders** - Don't rely on memory for scheduled tasks
3. **Batch similar tasks** - Group weekly tasks together
4. **Document steps** - Add sub-tasks for complex processes

---

### 📊 For Habit Building

1. **Start with one habit** - Don't overwhelm yourself
2. **Make it easy** - Lower the barrier (e.g., "Read 1 page")
3. **Track streaks** - Use stats panel to see progress
4. **Celebrate wins** - Review cycle count regularly
5. **Adjust as needed** - Habits take time to stick

---

### 🚀 Pro Tips

1. **Multiple cycles** - Create separate cycles for different contexts:
   - "Work Morning Routine"
   - "Evening Shutdown"
   - "Weekly Planning"

2. **Export backups** - Regularly export your cycles:
   - Menu → Settings → "Export Cycle"
   - Save `.mcyc` file to cloud storage

3. **Mobile & Desktop** - Use PWA on both:
   - Install on phone for on-the-go
   - Install on desktop for deep work

4. **Keyboard shortcuts** - Speed up task management:
   - See [Keyboard Shortcuts](#keyboard-shortcuts) below

5. **Undo/Redo** - Made a mistake?
   - Click undo button (↶) or **Ctrl+Z**
   - Redo with redo button (↷) or **Ctrl+Y**

## Troubleshooting

### Tasks not saving

**Problem:** Tasks disappear after refresh

**Solutions:**
1. Check browser settings - ensure cookies/localStorage enabled
2. Try different browser
3. Check if private/incognito mode (data doesn't persist)
4. Export cycle as backup before troubleshooting

---

### Recurring tasks not appearing

**Problem:** Scheduled recurring task doesn't show up

**Solutions:**
1. Check system time - ensure clock is correct
2. Wait 30 seconds - recurring system polls every 30s
3. Refresh page - forces re-check
4. Verify schedule in task settings (Edit Recurring)

---

### App not updating

**Problem:** New features missing or old bugs persist

**Solutions:**
1. **Hard refresh:** Ctrl+Shift+R (Windows) or ⌘+Shift+R (Mac)
2. **Clear cache:** Browser settings → Clear browsing data
3. **Reinstall PWA:** Uninstall app → Reinstall from browser
4. Check version number in Settings → About

---

### Progress bar stuck

**Problem:** Progress bar doesn't update

**Solutions:**
1. Refresh page
2. Check if hidden tasks exist (expand completed dropdown)
3. Export and reimport cycle
4. Contact support if persists

---

### Mobile app not working offline

**Problem:** PWA requires internet

**Solutions:**
1. Open app while online first (downloads cache)
2. Check PWA installation - should be "installed" not just bookmarked
3. Check storage permissions
4. Reinstall PWA

---

### Lost data / Need to restore

**Problem:** Accidentally deleted cycle or tasks

**Solutions:**
1. **Undo button** - Click ↶ (up to 20 undos per cycle)
2. **Import backup** - If you exported a `.mcyc` file
3. **Browser history** - Some browsers cache localStorage
4. **Prevention:** Export cycles regularly as backups!

### Common Questions

**Q: How many cycles can I create?**
A: Unlimited! Create as many as you need.

**Q: How many tasks per cycle?**
A: Recommended < 50 for performance. No hard limit.

**Q: Can I share cycles with others?**
A: Yes! Export as `.mcyc` file and share. Others can import it.

**Q: Does miniCycle sync across devices?**
A: Not built-in. Manual sync via export/import. Cloud sync may come in future.

**Q: Is my data private?**
A: Yes! All data stored locally in your browser. Nothing sent to servers.

**Q: Can I use miniCycle on multiple browsers?**
A: Yes, but data is per-browser. Use export/import to transfer.
